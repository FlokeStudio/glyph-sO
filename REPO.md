# glyph-sO Repository Note

`glyph-sO` is the Obsidian full-text search plugin in the Glyph 2.7 family.

- Main docs: `README.md` / `README.ru.md`
- Site: https://flokestudio.github.io/glyph-sO/
- Runtime modules: `services/search-engine.js` + `vendor/engine.js`
- Vendor stamp: `vendor/VERSION.json` (from glyph-s `npm run vendor:sync`)
- Engine dependency: [`glyph-s`](https://github.com/FlokeStudio/glyph-s)
- Companion plugin: [`glyph-miO`](https://github.com/FlokeStudio/glyph-miO)
